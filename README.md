# Smart Bill Splitter

A beginner-friendly web application built with Node.js and Express to split bills effortlessly, manage group expenses, and calculate balances.

## Features
- **Quick Split Calculator**: Quickly calculate splits including custom tax and tips.
- **Group Management**: Add and remove group members.
- **Expense Tracking**: Add, edit, and delete group expenses.
- **Balance Calculation & Settlements**: View individual balances and clear "who owes whom" breakdowns.

## Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

## Installation & Setup
1. Open your terminal in the project directory.
2. Install the required dependencies:
   ```bash
   npm install
   ```
3. Start the server:
   ```bash
   npm start
   ```
4. Open http://localhost:3000 in your browser.
